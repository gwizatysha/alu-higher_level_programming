# python-more_classes

Solutions for the Python More Classes project — building up a `Rectangle` class across 10 tasks, covering property getters/setters, area/perimeter, `__str__`/`__repr__`, `__del__`, class attributes for instance counting, static and class methods.

## Files
- `0-rectangle.py` — empty Rectangle class
- `1-rectangle.py` — width/height as properties with validation
- `2-rectangle.py` — adds area() and perimeter()
- `3-rectangle.py` — adds __str__
- `4-rectangle.py` — adds __repr__ (eval-able)
- `5-rectangle.py` — adds __del__
- `6-rectangle.py` — adds number_of_instances tracking
- `7-rectangle.py` — adds print_symbol class attribute
- `8-rectangle.py` — adds bigger_or_equal static method
- `9-rectangle.py` — adds square classmethod
