# python-inheritance

Solutions covering Python inheritance — introspection helpers (lookup, is_same_class, is_kind_of_class, inherits_from), a MyList class extending the built-in list, and a BaseGeometry -> Rectangle -> Square inheritance chain with validation and custom string representations.

## Files
- `0-lookup.py` — lists an object's attributes/methods
- `1-my_list.py` — list subclass with print_sorted()
- `2-is_same_class.py` — exact class check
- `3-is_kind_of_class.py` — class or subclass check
- `4-inherits_from.py` — strict subclass check (excludes exact match)
- `5-base_geometry.py` — empty base class
- `6-base_geometry.py` — adds area() (raises by default)
- `7-base_geometry.py` — adds integer_validator()
- `8-rectangle.py` — Rectangle with private validated width/height
- `9-rectangle.py` — adds area() and __str__
- `10-square.py` — Square built on Rectangle
- `11-square.py` — Square with its own __str__
