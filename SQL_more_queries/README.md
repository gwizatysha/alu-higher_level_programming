# SQL_more_queries

This project covers advanced SQL queries, including subqueries, joins,
and user/privilege management in MySQL.

## Tasks

- 0-privileges.sql: List privileges of MySQL users
- 1-create_user.sql: Create a root user
- 2-create_read_user.sql: Create a read-only user
- 3-force_name.sql: Create table with NOT NULL constraint
- 4-never_empty.sql: Create table with DEFAULT value
- 5-unique_id.sql: Create table with UNIQUE constraint
- 6-states.sql: Create states table
- 7-cities.sql: Create cities table with foreign key
- 8-cities_of_california_subquery.sql: Subquery example
- 9-cities_by_state_join.sql: JOIN example
- 10-16: Queries on the hbtn_0d_tvshows database
