# SQL_introduction

An introduction to relational databases and SQL using MySQL: creating
and deleting databases and tables, inserting, updating, and deleting
records, and writing basic queries with WHERE, ORDER BY, GROUP BY,
and aggregate functions.

## Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-list_databases.sql` | Lists all databases on the MySQL server |
| 1 | `1-create_database_if_missing.sql` | Creates the database `hbtn_0c_0` |
| 2 | `2-remove_database.sql` | Deletes the database `hbtn_0c_0` |
| 3 | `3-list_tables.sql` | Lists all tables of a database |
| 4 | `4-first_table.sql` | Creates the table `first_table` |
| 5 | `5-full_table.sql` | Prints the full description of `first_table` |
| 6 | `6-list_values.sql` | Lists all rows of `first_table` |
| 7 | `7-insert_value.sql` | Inserts a new row into `first_table` |
| 8 | `8-count_89.sql` | Counts records with `id = 89` in `first_table` |
| 9 | `9-full_creation.sql` | Creates `second_table` and inserts multiple rows |
| 10 | `10-top_score.sql` | Lists records ordered by score (top first) |
| 11 | `11-best_score.sql` | Lists records with `score >= 10` |
| 12 | `12-no_cheating.sql` | Updates Bob's score to 10, by name only |
| 13 | `13-change_class.sql` | Removes records with `score <= 5` |
| 14 | `14-average.sql` | Computes the average score |
| 15 | `15-groups.sql` | Counts records grouped by score |
| 16 | `16-no_link.sql` | Lists records with a non-null name, by descending score |

Each script starts with a comment describing what it does, and all
SQL keywords are written in uppercase.
