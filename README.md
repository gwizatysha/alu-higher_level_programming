# alu-higher_level_programming

This repository contains exercises and projects for the Higher-Level
Programming curriculum, covering Python fundamentals, object-oriented
programming, file I/O, JSON serialization, and more.

## Directories

- `python-hello_world`
- `python-if_else_loops_functions`
- `python-import_modules`
- `python-data_structures`
- `python-more_data_structures`
- `python-exceptions`
- `python-classes`
- `python-more_classes`
- `python-inheritance`
- `python-everything_is_object`
- `python-input_output`

Each directory includes the solution files for that project's tasks,
following PEP8 style guidelines.
