# python-input_output

This project covers file input/output in Python: reading and writing
text files, JSON serialization and deserialization, and building
simple serializable classes.

## Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-read_file.py` | Read a text file and print it to stdout |
| 1 | `1-write_file.py` | Write a string to a text file |
| 2 | `2-append_write.py` | Append a string to a text file |
| 3 | `3-to_json_string.py` | Return the JSON representation of an object |
| 4 | `4-from_json_string.py` | Return an object from a JSON string |
| 5 | `5-save_to_json_file.py` | Write an object to a file as JSON |
| 6 | `6-load_from_json_file.py` | Create an object from a JSON file |
| 7 | `7-add_item.py` | Add arguments to a list and save to `add_item.json` |
| 8 | `8-class_to_json.py` | Return a serializable dictionary from an object |
| 9 | `9-student.py` | `Student` class with a `to_json` method |
| 10 | `10-student.py` | `Student` class with a filterable `to_json` |
| 11 | `11-student.py` | `Student` class with `to_json` and `reload_from_json` |
| 12 | `12-pascal_triangle.py` | Compute Pascal's Triangle |

All code follows PEP8 style guidelines and uses the `with` statement
for file handling where required.
