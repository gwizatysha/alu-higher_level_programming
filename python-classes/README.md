# python-classes

Solutions for the Python Classes project — building up a `Square` class step by step across 7 tasks, covering private attributes, type/value validation, properties (getters/setters), and printing with position offsets.

## Files
- `0-square.py` — empty Square class
- `1-square.py` — Square with a private size attribute
- `2-square.py` — adds size validation
- `3-square.py` — adds an area() method
- `4-square.py` — size becomes a property (getter/setter)
- `5-square.py` — adds my_print() to draw the square
- `6-square.py` — adds a position property, offsets my_print() accordingly
