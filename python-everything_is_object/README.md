# python-everything_is_object

Answers exploring how Python handles objects, references, mutability, and identity — the difference between `==` (equality) and `is` (identity), how mutable vs immutable objects behave when passed to functions, and CPython's constant-folding/interning behavior for small ints, strings, and tuples.

## Files
- `0-answer.txt` through `18-answer.txt`, `20-answer.txt` through `28-answer.txt` — one-line answers to the conceptual questions
- `19-copy_list.py` — returns a shallow copy of a list
